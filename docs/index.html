Why I built it

Make the data easier to read.

Motorsport produces rich timing and telemetry data, but raw tables can be hard to interpret. Trackside Replay brings those details together in an interactive view for fans and aspiring motorsport engineers.

This project began as a hackathon build and grew into a way to explore race strategy, driver pace, and the story behind each lap.
